# Summary Report: “Weekend Knowledge Sharing Session”

### Event Objectives

- Share practical experiences about building long-term learning habits in the technology field.
- Introduce effective ways to use AI and prompt engineering to improve development productivity.
- Present AI-assisted software development workflows that can support planning, coding, testing, and documentation.
- Provide career guidance for students preparing to enter the technology job market.
- Help students understand the importance of combining technical skills, soft skills, and a continuous learning mindset.

### Speakers

- **Huỳnh Hoàng Long** – Addicted to Learning Like You're Addicted to Social Media
- **Thịnh Nguyễn** – Automated Prompt Engineering: Enhancing LLM Output Quality
- **Khang Nguyễn** – Career Opportunities & Mindset for Entering the Job Market
- **Thảo Nguyễn Phương** – BMAD Method – AI-Driven Development Workflow

### Key Highlights

#### Building a continuous learning habit

The session emphasized that learning should become a consistent habit rather than something done only when there is an assignment or deadline. The speaker compared learning with the habit of using social media every day, making the idea easier to understand and apply.

Key points included:

- Treat learning as a daily activity instead of a short-term goal.
- Build a personal learning system with clear topics, resources, and practice time.
- Stay curious and actively explore new tools, frameworks, and technologies.
- Learn through small but regular actions such as reading documentation, watching tutorials, and building mini projects.
- Maintain motivation by connecting learning goals with real career development.

#### Automated Prompt Engineering

This topic introduced the idea of improving LLM output quality through automated prompt optimization. Instead of manually rewriting prompts many times, automated prompt engineering can help make AI responses clearer, more consistent, and more suitable for practical use.

Important ideas from this part included:

- Prompt quality directly affects the usefulness of AI-generated responses.
- Automated prompt optimization can reduce manual effort and save development time.
- Well-structured prompts help AI provide more accurate and stable results.
- Prompt engineering can support software development, documentation, testing, and problem solving.
- Developers still need to review and validate AI outputs instead of relying on them completely.

#### Career opportunities and job market mindset

The career sharing session provided practical advice for students who are preparing for internships or full-time jobs in the technology industry. The speaker explained that employers look not only at technical knowledge, but also at attitude, communication, teamwork, and problem-solving ability.

Main points included:

- Students should prepare early by improving both technical and soft skills.
- Real projects and practical experience are important when building a CV or portfolio.
- A good portfolio should clearly show what the student has built and what role they played in each project.
- Communication and teamwork are necessary in real working environments.
- A growth mindset helps students handle challenges and keep improving after graduation.

#### BMAD Method – AI-driven development workflow

The BMAD Method introduced a structured approach to using AI in the software development lifecycle. The session showed that AI can support more than just code generation. It can also assist with requirement analysis, planning, implementation, testing, and documentation.

Key ideas included:

- AI can be used throughout the software development process, not only during coding.
- A clear workflow helps developers use AI more effectively and avoid random prompting.
- AI agents can support different roles in a project, such as planning, development, testing, and review.
- The BMAD Method provides a useful reference for organizing AI-assisted development tasks.
- Open-source AI development workflows can help students learn modern software engineering practices.

### Key Takeaways

#### Learning Mindset

- **Continuous learning** is essential for long-term growth in the technology industry.
- Building a learning routine helps students improve steadily over time.
- Developers should not wait for tasks or deadlines before learning something new.
- Curiosity and self-discipline are important qualities for adapting to fast-changing technologies.
- Learning should be connected with practical projects to make knowledge easier to remember and apply.

#### AI and Prompt Engineering

- **Prompt Engineering** is an important skill when working with AI tools and LLMs.
- Clear and structured prompts can improve the quality of AI-generated results.
- Automated prompt engineering can help increase productivity and reduce repeated manual refinement.
- AI can support many development activities, including coding, debugging, documentation, and testing.
- Developers must evaluate AI responses carefully to avoid incorrect or unsuitable outputs.

#### Career Preparation

- Technical skills are important, but they are not enough by themselves.
- Employers also value communication, teamwork, responsibility, and problem-solving skills.
- Practical projects help students demonstrate their real abilities more clearly.
- A strong portfolio can create advantages when applying for internships or jobs.
- Students should build a professional mindset early, even during university and internship periods.

### Development Workflow

- AI-assisted workflows can make software development more organized and efficient.
- Using AI in planning and requirement analysis can reduce confusion before implementation.
- AI can support implementation, testing, documentation, and code review.
- Structured methods such as BMAD help developers use AI with a clearer purpose.
- Combining AI tools with human review can improve productivity while maintaining project quality.

### Applying to Work

- Build a consistent learning routine and update technical knowledge regularly.
- Apply prompt engineering techniques when using AI for coding, debugging, and documentation.
- Use AI tools to support project planning, task breakdown, testing, and report writing.
- Explore the BMAD Method as a reference for improving the development workflow in group projects.
- Continue building practical projects to strengthen technical skills and portfolio quality.
- Improve communication, teamwork, and problem-solving skills during internship tasks.
- Apply the lessons from the event to the GreenLens Kids project, especially when working with AI-related features and frontend development tasks.
